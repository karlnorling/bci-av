Why there is no component per symbol

Section titled “Why there is no component per symbol”

The sibling @ghs-hazard-pictograms packages generate one component per pictogram, which works for 38 of them. With 6,551 it would mean thousands of modules for no benefit, so you pass a symbol from the registry instead.
