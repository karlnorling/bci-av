Blissymbolics is a semantic graphical language used in augmentative and alternative communication. Unlike an icon set it is generative: symbols compose into new words, and BCI records how each compound is built.

Not just pictures

Every symbol carries BCI’s derivation, so housework tells you it is work + house — real semantic structure, not a filename.

19 languages

Glosses in English, Swedish, Norwegian, Finnish, Hungarian, German, Dutch, Afrikaans, Russian, Icelandic, Lithuanian, Latvian, Polish, French, Spanish, Portuguese, Italian, Danish and Esperanto.

Accessible by default

All three renderers inject the accessible name and description into the SVG itself, so assistive technology reads the graphic rather than a wrapper.

Versioned against BCI

The registry records which Authorized Vocabulary edition it was built from, and CI fails if the two drift apart.

The symbols are not public domain

The artwork and metadata are CC BY-SA 4.0 by Blissymbolics Communication International. Shipping them obliges you to attribute BCI, and to share alike if you modify the symbols. See Licensing.
