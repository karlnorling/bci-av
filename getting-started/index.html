Getting started

Install

Section titled “Install”
  • React
  • Vue 3
  • Web Components
  • CSS
sh npm install @bci-av/core @bci-av/react
sh npm install @bci-av/core @bci-av/vue
sh npm install @bci-av/core @bci-av/elements
sh npm install @bci-av/css @bci-av/assets

@bci-av/core holds the registry and is the only package with no peer dependencies. Everything else builds on it.

Look a symbol up

Section titled “Look a symbol up”

Prefer getSymbolByBciAv when you persist a reference. BCI-AV numbers are not reused between editions; slugs follow their gloss and can change.

Render it

Section titled “Render it”
  • React
  • Vue 3
  • Web Components
  • CSS

The symbol is set as a property, not an attribute — an attribute would mean shipping all 6,551 symbols to the page just so the element could look one up.

Backgrounds resolve into @bci-av/assets, so install both.

Accessible names

Section titled “Accessible names”

All three renderers inject a <title> and <desc> into the SVG and point aria-labelledby at them, so screen readers describe the graphic itself.

The description defaults to BCI’s derivation, which for a compound symbol is genuinely useful: house-work reads as “(work + house: work to maintain a house)”.

Use getName(symbol, language) rather than reading names[language] directly — the entry is absent for untranslated symbols, and where present it holds every synonym in one comma-separated string.
