Blissymbolics is a semantic graphical language used in augmentative and
alternative communication. Unlike an icon set it is **generative**: symbols
compose into new words, and BCI records how each compound is built.

<CardGrid>
  <Card title="Not just pictures" icon="puzzle">
    Every symbol carries BCI's derivation, so `housework` tells you it is `work + house` — real
    semantic structure, not a filename.
  </Card>
  <Card title="19 languages" icon="translate">
    Glosses in English, Swedish, Norwegian, Finnish, Hungarian, German, Dutch, Afrikaans, Russian,
    Icelandic, Lithuanian, Latvian, Polish, French, Spanish, Portuguese, Italian, Danish and
    Esperanto.
  </Card>
  <Card title="Accessible by default" icon="approve-check">
    All three renderers inject the accessible name and description into the SVG itself, so assistive
    technology reads the graphic rather than a wrapper.
  </Card>
  <Card title="Versioned against BCI" icon="seti:clock">
    The registry records which Authorized Vocabulary edition it was built from, and CI fails if the
    two drift apart.
  </Card>
</CardGrid>
